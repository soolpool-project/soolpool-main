## 🌐 Overview

**SOOLPOOL** is a modern, single-file OSINT (Open-Source Intelligence) framework built in Python, designed for security researchers, penetration testers, red teamers, and OSINT enthusiasts who need a fast, terminal-based reconnaissance toolkit.

It bundles **28 investigative modules** across four major categories — **domain**, **website**, **email**, and **phone** — into a single, portable script with an animated orange-themed CLI interface.

Unlike bloated commercial tools or illegal "пробив" services, SOOLPOOL operates **exclusively on publicly available data** — DNS records, WHOIS registries, HTTP responses, and free public APIs. No breached databases, no leaked credentials, no criminal liability.

Whether you're auditing your own infrastructure, conducting authorized penetration testing, or learning OSINT methodology, SOOLPOOL gives you a professional, self-contained toolkit in one file.

## 💡 Why SOOLPOOL?

### 🎯 Built for Real Work

Most OSINT tools fall into two extremes: **either too simple** (single-purpose scripts like `whois` or `dig`) **or too complex** (SpiderFoot, Maltego — heavy frameworks that take hours to configure).

SOOLPOOL hits the sweet spot: **28 tools in one file**, zero configuration, instant startup. Run it from any terminal, on any OS, without installing a framework.
